# NEXUS 5.2 Experience preview
Design: https://www.figma.com/design/rPfxo1DQiVHo4rdh6u5gls
App-scoped dark/light palettes, three accents, two message densities, optional reduced motion. Preferences use the existing account settings; no schema change. Narrow header and composer, single Auto option, keyboard dismissal, and IME-safe Enter. Existing model and billing policies unchanged. Figma is a proposed design, not a pixel-exact capture. New automated viewport checks use mock authentication; real-device iOS keyboard and real account preference persistence still require validation. Package version stays at 5.0 RC1 until coordinated release.
