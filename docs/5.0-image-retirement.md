# NEXUS 5.0 — Görsel üretimi kaldırma

Hugging Face sağlayıcı kodu ve arayüz düğmesi kaldırıldı. Eski `/api/image` POST adresi 410 döndürür; dış ağ isteği, token erişimi veya kota işlemi yapmaz. Eski sohbetlerdeki imageUrl alanı ve geçmiş görsel sayacı korunur. Görsel yükleme/analiz ve PDF/dosya özellikleri etkilenmez. Gerçek OpenRouter görsel analizi test edilmedi. Canlı 4.0 ve Render ortam değişkenleri değiştirilmedi; 5.0 dağıtımından sonra kullanılmayan HF anahtarları ayrıca incelenebilir. Ödeme ve premium erişim kapalı kalır.
