# NEXUS 5.0 — Plan önizlemesi

Ayarlar > Hesap ve veri bölümünde sunucu tarafından doğrulanan hesap sınıfı ve planlanan 399 TL / ay, 5 USD ortak API bütçesi gösterilir. Bu bakiye değildir. Premium erişim kapalıdır; ödeme düğmesi yoktur. Sohbet yanıtında sunucunun bildirdiği yönlendirilen model kimliği gösterilir. Token istatistiklerinde sağlayıcının verdiği değerler mevcutsa kullanılır; yoksa tahminler korunur. Model kimliği sağlayıcının fiziksel backend'inin bağımsız doğrulaması değildir. Kredi SQL'i izole CI'da doğrulanmış adaydır, canlı Supabase'e kurulmamıştır.
