# Owner-only Pro design preview

The authenticated status endpoint derives the display plan from the existing server-side administrator UUID check. Other accounts remain Free regardless of metadata. The owner settings screen has two disabled premium model placeholders. No changes to the chat router, API catalog, billing, credentials, database, or provider access. This is not a subscription or model integration. Existing 5.0 RC1 live deployment is unchanged until review. OpenRouter terms require users to be at least 18; do not use this preview to bypass that requirement. No actual provider calls are part of this change.

Browser checks use synthetic authenticated client fixtures to verify ordinary Free accounts have no owner-specific controls, both owner model placeholders are disabled, and opening the settings does not send chat requests. Admin Center labels legacy metadata counts separately from actual access. Production authentication, actual account identity, provider inference and billing are not tested or changed.
