# NEXUS 4.0 Alpha 1

Geliştirme tabanı 3.3 RC2 ve dalı `feature/nexus-4.0`. Mevcut Render servisi ve Supabase projesi için yeni servis veya şema değişikliği gerekmiyor.

| Modül | Alpha kapsamı |
| --- | --- |
| Auto 2.0 | Açıkça seçilen Auto modunda, geçici sağlayıcı hatalarında ikinci bir ücretsiz model için en fazla bir deneme. Her deneme mevcut kotadan ayrı rezervasyon alır. Ücretli web aramasında yedek deneme yapılmaz. |
| Thinking Mode | Hızlı, dengeli ve derin analiz profilleri. Hızlı profil çıkış sınırını azaltır. Derin analiz yönlendirmeyi ve cevap talimatını değiştirir. |
| Multi-AI | Aynı soruyu iki ayrı ücretsiz modele sırayla sorar. Kullanıcı her çağrıyı başlatır, cevapları ayrı okur ve dosyaya aktarabilir. İsteğe bağlı sentez üçüncü ve ayrı bir çağrıyla oluşturulur. |
| Deep Research 2.0 | Vikipedi ve Crossref araması, yalnız Crossref seçeneği, kaynak numaralı özet ve dosyaya aktarım. Crossref sonuçları yayın kaydıdır. |
| Memory 3.0 | Kullanıcının onayladığı notlarda sözcük eşleşmelerine göre sıralama, eski sohbetler için mevcut proje sınırları. Anlamsal embedding ileriki kapsamda. |
| Agent Mode | Yazı planı ve kullanıcının açıkça başlattığı taslak aşaması. Akış modelden metin alır ve dış işlem yürütmez. |
| Code Lab Pro | Tarayıcıdaki sınırlı sayısal dil, sınırlı döngüler ve metin çıktısı. Tam Python için ayrı ve doğrulanmış bir izolasyon gerekir. |
| Artifacts 2.0 | Yerel metin dosyası açma, düzenleme ve mevcut ofis biçimleriyle dışa aktarma. |
| Voice 2.0 | Mikrofon başlatma hatalarının gösterimi ve tarayıcının konuşma tanıma hizmetine dair bilgi. Mevcut dil ve okuma hızı ayarları kullanılır. |
| Admin Center 2.0 | Yöneticiye özel UTC kota özeti ve doluluk durumu. Kota düzenleme mevcut Supabase yönetiminde kalır. |

## Sürüm doğrulaması

GitHub Actions dalda çalışacak şekilde yapılandırıldı. Stable kararı için birim testleri, üretim derlemesi, bağımlılık denetimi, anonim API kontrolleri, masaüstü ve mobil tarayıcı testleri, gerçek test hesabıyla özel ekranlar ve sağlayıcı çağrıları, fiziksel cihazda mikrofon ve canlı dağıtım doğrulaması gerekir.
