# NEXUS 3.3 Alpha 1
Staged only; main remains 3.2.1. Live database schema is additive. No paid provider activated.
- NEXUS Auto chooses a concrete eligible zero-price catalog model. Explicit choices are checked server-side; context/vision validated. Catalog failure fails closed. Only OpenRouter chat supported in this alpha.
- Daily UTC request quotas are atomic in database. Defaults: 50/user, 500/global; image attempts 5/user and 30/global. Estimated paid reservation caps 0.25 USD/user and 2 USD/global; paid mode OFF. No refunds on failed attempts to avoid abuse. This is not a hard provider billing guarantee; additional provider charges can vary. Set provider-side spend limits independently. HF has request quotas, not dollar estimates. Web plugin incurs a conservative reservation and is disabled while paid mode off. Legacy code execution intentionally disabled in alpha.
- /admin requires authenticated ID exactly matching NEXUS_ADMIN_USER_ID server environment variable. No automatic promotion or client-controlled roles. Read-only dashboard; settings editable via authorized Supabase dashboard. Never use NEXT_PUBLIC_ for this ID configuration or secret keys.
- Build/test before merge; verify admin ID. Existing chat/Canvas/GEMS/voice routes remain. Rollback by leaving main untouched; schema additions do not enforce quotas on 3.2.1.
- Actual provider cost stored when present; old logs remain estimates. No credit ledger, no payments, no sandbox code execution in Alpha 1.
