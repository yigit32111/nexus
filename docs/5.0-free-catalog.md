# NEXUS 5.0 — Free model catalog safety

The authenticated catalog and chat router share one cache and parser. Only explicit :free model IDs with valid text modalities, supported context and zero known and additional reported prices are listed or routed. Paid models, aliases, malformed pricing and paid web are rejected. Strict filtering may hide otherwise usable models if the provider changes its catalog schema; this is intentional until reviewed. Requests retain zero max_price constraints; real provider behavior is not verified. A two-minute cache can be stale, so this is not a billing guarantee. Existing Hugging Face image generation is separate and may carry provider-side costs; no changes to its configuration or credentials were made. No payments or premium access enabled.
