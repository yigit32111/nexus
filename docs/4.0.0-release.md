# NEXUS 4.0.0 — Yayın paketi

Bu paket 4.0 Alpha 1'in desteklenen özellik kapsamını sürüm numarası, PWA adı ve yayın belgelerinde tutarlı hale getirir. Yeni ücretli hizmet, veri tabanı değişikliği veya yetki genişlemesi içermez.

## Desteklenen kapsam

- Auto 2.0: ücretsiz OpenRouter model seçimi, uygun geçici hatada kota kapsamındaki bir alternatif deneme.
- Thinking Mode: hızlı, dengeli, derin analiz profilleri.
- Multi-AI: iki modelin yanıtları ve isteğe bağlı sentez.
- Agent Mode: kullanıcı onaylı plan ve yazı taslağı; dış sistemde otonom işlem yok.
- Deep Research 2.0: Wikipedia ve Crossref yayın kayıtları; tam makale metni yok.
- Memory 3.0: onaylı notlar, sözcük/kavram eşleştirme, isteğe bağlı geçmiş hatırlama; embedding yok.
- Code Lab: sınırlandırılmış Python benzeri sayısal dil; tam Python değil.
- Artifacts: PDF, DOCX, XLSX, PPTX, ZIP, CSV, Markdown ve TXT.
- Voice: tarayıcı diktesi ve seslendirme; gerçek zamanlı ses modeli değil.
- Admin Center: salt okunur hesap, kullanım ve kota göstergeleri; gerçek ödeme altyapısı yok.

## Yayın kontrolleri

Önceki canlı Alpha commit e029ebc4c57dfc571f5e90e0f1711b032d36bac6 için 36 birim testi, üretim derlemesi, 30 anonim erişim kontrolü, Chromium ve WebKit giriş testleri, çalışma alanı ve simüle ses kontrolleri, çalışma zamanı npm denetimi başarılıydı. Yeni commit için CI yeniden çalıştırılır. Tarayıcı çalışma alanı testleri benzetilmiş Supabase/AI yanıtları kullanır.

Tam sürüm doğrulaması için gerçek test hesabıyla giriş, sohbet/model çağrıları, kullanıcı verisi izolasyonu, belge indirme, gerçek iPhone ses ve PWA deneyimi ile canlı dağıtım sonrası doğrulama gerekir. Fiziksel cihaz, sağlayıcı uçtan uca testi ve yük testi yapılmış kabul edilmez. Sıfır npm bulgusu tüm uygulamanın güvenli olduğunu garanti etmez. Bilinen Supabase parola koruması uyarısı ayrıca incelenmelidir. Yayın paketi, mevcut Alpha kapsamını aşan işlevleri tamamlanmış olarak tanımlamaz.
