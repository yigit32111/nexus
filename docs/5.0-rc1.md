# NEXUS 5.0.0-rc.1 — Release Candidate

## Scope
- Auto 3.0, explicit free model IDs, shared catalog parser and server-side zero-price request constraints.
- Proposed Free/Pro plans, public /plans preview and settings navigation. 399 TRY and 5 USD shared monthly budget are proposals, not charges or entitlements.
- Isolated PostgreSQL credit ledger candidate: atomic reservations, duplicate request rejection, idempotent settlement, overage blocking. Production Supabase schema unchanged.
- Model ID and provider-reported token statistics when available.
- Callback origin and document deletion hardening, inherited 4.0 tools.
- Hugging Face integration retired; /api/image returns 410 without provider calls. Upload and image analysis remain, stored image history unchanged.
- No real billing until 10.0. Premium calls are disabled. No checkout, payment keys, card fields or billing callbacks.

## Release gates and limitations
- RC must pass its own Release CI and Credit Engine CI.
- Real authenticated chat, real OpenRouter catalog/vision/streaming, account isolation and physical iPhone not yet verified. Free model availability and upstream zero cost are not guaranteed by local tests. No benchmark of output quality.
- Existing 4.0 live deployment is unchanged. Do not merge or deploy without checking the RC tests and explicitly deciding release readiness.
- No production wallet provisioning, paid inference, or payment integration in this RC. Payment activation deferred to 10.0, subject to review and guardian involvement.
- Rollback: keep the current live 4.0 commit; RC introduces no production schema change. Historical credit test schema is not a migration to run on production.

## RC1 account-limit follow-up
OpenRouter documents shared free-tier request limits. A 429 will not trigger another model request, and a bounded numeric Retry-After header is forwarded when available. A 402 will not fall back to paid inference. See https://openrouter.ai/collections/free-models and https://openrouter.ai/blog/tutorials/llm-api-rate-limits/. Provider-side capacity and real account-specific quota are still unverified. No credits purchased or paid API calls made.
