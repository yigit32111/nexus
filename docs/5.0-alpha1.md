# NEXUS 5.0 Alpha 1 — Security & Plans

İlk geliştirme adımı; canlı 4.0 korunur. Önerilen teklif: Free ücretsiz Auto, Pro 399 TL/ay ve iki model için toplam aylık 5 USD API kullanım bütçesi. Fiyat henüz kesinleşmedi, ödeme ve ücretli erişim kapalı. Model kimlikleri önerilen önceliklerdir; katalogda güncel olarak bulunmaları garanti değildir. Gerçek sağlayıcı çıkarım çağrıları yapılmadı.

Auto 3.0: ERNIE günlük sohbet; Nemotron 3 Ultra analiz; Particle-1 kod; Nemotron 3.5 Super VL görsel; Gemma 4 yedek. Canlı katalog fiyatı ve bağlam/görsel yeterliliği seçimden önce kontrol edilir. Katalogda model kalmazsa diğer uygun ücretsiz modeller değerlendirilir. Model kalitesi için ayrıca benchmark gerekir.

İlk güvenlik adımları: ücretli katalog seçimleri ve web eklentisi kapalı; varsayılan Auto; callback sabit uygulama origin'i; güvenilir sunucu app_metadata üzerinden plan gösterimi. Pro bütçe matematiği saf birim testidir, gerçek cüzdan değildir. SQL atomik rezervasyon, kullanım mutabakatı, ödeme webhook doğrulaması, hak süreleri, iade ve faturalandırma, gerçek sağlayıcı testi ve veliyle ticari koşulların değerlendirilmesi sonraki aşamalardır. Groq/Vercel entegrasyonu henüz yok.
