# NEXUS 5.1 — Smart Context
Local deterministic extractive compression of the active conversation only. Existing server baseline (last 32 messages, each capped to 24k characters) remains the input. Default enabled; user can disable in Memory settings. No new provider requests, data storage, cross-chat retrieval, database migrations, billing or premium changes.
When serialized history exceeds 24k chars, preserve a contiguous suffix of at least 12 messages without additional truncation. Include up to five short, literal older excerpts ranked by query overlap, as an explicitly labeled user-reference message, never a fabricated summary or system instruction. If reference JSON is >2200 chars or not smaller than original, retain original. Skip short/ambiguous queries, common exact-history/code/file terms, all attachments and histories ending in assistant. Existing per-message truncation and original history cap still apply. The threshold is soft, not a context-window guarantee. Long or multilingual requests can defeat keyword heuristics; disable Smart Context when exact context is required. Character reductions are measurable estimates, not guaranteed token or cost savings. Existing memory and project boundaries unchanged.
