# NEXUS 3.3 Workspace beta
Existing Core, quotas, admin, share, GEMS and Canvas retained. Projects use owner-only RLS and composite ownership FK. Project notes are bounded plaintext; not a full Storage document manager. Memory is keyword-ranked approved memory and bounded extractive older-message summary, not embeddings. Research uses two Wikipedia editions, source links, and optional AI synthesis via existing quotas; no general web crawling, durable queue or independent source verification. Interactive charts use validated data only. Code Lab is a bounded arithmetic interpreter, not general Python or JavaScript. DOCX/XLSX/PPTX/ZIP/CSV/MD generated via authenticated endpoint; PDF uses browser print. Browser speech supports selectable language, speed, interruption and stale-turn guards; no realtime provider or audio storage. No paid services provisioned. Test deployment before merge.
