# NEXUS 5.1 preview — Cost Intelligence
Design: https://www.figma.com/design/n1h7FEsfnb7SlYCe5BgOkE
First phase: responsive Admin Center 3.0, original NEXUS logo, Manrope, responsive metrics, seven-day UTC token chart and model breakdown. Mockup values are examples; live UI reads existing usage records.

The admin authorization runs before the server service-role query. No user IDs or content are selected for cost reporting. Last seven UTC calendar days (today included), newest first, exact count, max 1000 rows and explicit partial-data warning if actual returned count differs. Read errors are not treated as zero. Token counts may be estimates. Null/invalid cost is unknown; explicit zero is known zero. Cost uses integer micro-USD; known cost total is not a billing ledger. No new dependency, database migration, actual payment, model access, credit allocation or provider calls. Package version remains 5.0 RC1 until a verified 5.1 release; preview labels are scoped to admin. Smart Context is separate, not implemented in this phase.
